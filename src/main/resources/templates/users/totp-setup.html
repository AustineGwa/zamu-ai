Set up your authenticator app

Zamu team accounts can see every client, so they need a second step at login. You'll only do this once.

  1. Open an authenticator app on your phone (Google Authenticator, Microsoft Authenticator or 1Password).
  2. Add an account and choose enter a setup key. Use this key, as a time-based key:

    ABCD EFGH IJKL MNOP

    Using a password manager? Copy the setup link

    otpauth://...

  3. Enter the 6-digit code the app shows.
